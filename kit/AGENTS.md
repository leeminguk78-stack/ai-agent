# Правила рабочей папки ИИ-агента

> Этот файл обновляется автоматически при каждом запуске агента — не редактируй его.
> Свои правила и заметки пользователь пишет в `CLAUDE.md` (ниже строки `@AGENTS.md`) или в `NOTES.md`.
> Эти правила читают все движки агента (Claude Code, Codex).

## Окружение
- Ты работаешь на телефоне Samsung Galaxy Z Fold6: Ubuntu (proot) внутри Termux. Папка `/workspace` — проекты пользователя.
- Превью любых файлов: `http://127.0.0.1:8766/<путь внутри /workspace>/` — пользователь открывает его на телефоне. Давай эту ссылку в ответе.
- Не запускай серверы и другие долгие фоновые процессы — превью уже работает.
- Есть `python3`, `node`, `git`, `gh` (вход в GitHub уже выполнен).
- Отвечай по-русски, кратко: что сделано, где файлы, как проверить или установить.
- Если есть `NOTES.md` — учитывай заметки пользователя оттуда.

## Сайты
- Каждый сайт — в `sites/<имя>/`, главная страница `index.html`.
- Вёрстка адаптивная: узкий экран телефона и широкий экран раскрытого Fold.
- После изменений проверь: HTML без незакрытых тегов, `node --check` для JS, страница открывается в превью (код 200).

## Android-приложения по описанию
Android-приложение = веб-приложение (HTML/CSS/JS) в оболочке WebView. Оно собирается в APK в GitHub Actions и работает офлайн.

1. **id приложения** — латиница в нижнем регистре, цифры и `_`, начинается с буквы: `calc`, `todo_list`, `snake`.
2. **Код** — в `android/<id>/www/`, точка входа `index.html`.
   - Всё локально: никаких CDN и внешних шрифтов (если пользователь не просил иное) — приложение должно работать без интернета.
   - Адаптивно под телефон и раскрытый Fold; крупные кнопки для пальцев; `<meta name="viewport" content="width=device-width,initial-scale=1">`.
   - Данные — в `localStorage` или IndexedDB.
   - Приложение открывается как `https://app.local/index.html`: можно ES-модули, `fetch()` к своим файлам, `alert/confirm`.
   - Иконка (по желанию): `android/<id>/www/icon.png`, 512×512, PNG.
3. **Описание** — `android/<id>/app.json`:
   ```json
   {"name": "Калькулятор", "theme": "light", "color": "#ffffff"}
   ```
   `theme` — `light` или `dark` (цвет значков статус-бара), `color` — фон полос системы, как фон приложения.
4. **Проверка до сборки**: `node --check` для каждого JS-файла; открой превью `http://127.0.0.1:8766/android/<id>/www/` (код 200); проверь логику, которую можно проверить скриптом.
5. **Сборка APK**: `bash /workspace/.agent/apk.sh <id>`
   - Скрипт отправит приложение в закрытый репозиторий `ai-agent-apps` на GitHub, дождётся сборки (обычно 2–5 минут) и выведет строку `APK_URL=…`.
   - Запускай как обычную команду (не в фоне) — ей разрешено работать до 15 минут.
   - Если сборка упала — скрипт покажет журнал ошибки: исправь причину и запусти снова.
6. **Ответ пользователю**: ссылка на APK и как установить — открыть ссылку (в браузере, где выполнен вход в GitHub: репозиторий закрытый) → скачать → установить. Обновления этого же приложения ставятся поверх старой версии.

Изменить приложение: правь файлы в `android/<id>/`, проверь, снова запусти `apk.sh` — версия обновится по той же ссылке.
