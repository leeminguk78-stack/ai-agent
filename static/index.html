Codex

Работает по подписке ChatGPT в той же Ubuntu, по тем же правилам (AGENTS.md), тоже собирает APK.

Как подключить Codex (один раз)

1. На chatgpt.com: аватар → Settings → Security → включи «Device code authorization for Codex».

2. В Termux, по одной команде:

proot-distro login ubuntu
curl -fsSL https://chatgpt.com/codex/install.sh | sh
/root/.local/bin/codex login --device-auth

3. Открой в Chrome ссылку https://auth.openai.com/codex/device, войди в ChatGPT и введи код из Termux (действует 15 минут). Когда Termux сообщит об успешном входе:

exit

Обычный codex login (через localhost) на Android часто падает с ошибкой «Token exchange failed» — поэтому вход по коду.
